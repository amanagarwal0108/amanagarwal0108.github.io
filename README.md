# Aman Agarwal portfolio

This is a dependency-free static portfolio, ready for GitHub Pages. Open `index.html` in a browser to preview it locally.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io` (or use an existing repository).
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. GitHub will publish the site at `https://YOUR-USERNAME.github.io`.

## Before publishing

The portfolio content is grounded in `aman-5.pdf`, including all listed projects, exact employment dates, education, certifications, public contact details, and project metrics. Replace the AA avatar with a professional headshot before publishing if desired.

The typography is calibrated to the reference site's measured desktop sizes, with mobile-specific equivalents.

The GitHub Pages URL is configured as `https://amanagarwal0108.github.io/`. The social-share preview will activate after the first successful publish.
